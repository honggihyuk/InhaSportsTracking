# 후반기 기능 실증 화면 (sports_video_1)

- 캡처: Playwright 헤드리스 Chrome (GPU WebGL), 1920×1080, 2026-11-05
- 코드: `claude/sam3-video-tracking` (보정 개선 · RF-DETR 파인튜닝 · 등번호 인식 · SAM3 영상 추적 모두 포함)
- 데이터: 정밀 모드 전체 분석 결과 — 파인튜닝 RF-DETR + SAM3(프레임 마스크 + 영상 추적) + SigLIP2 팀 + GLM-OCR 등번호 + 앵커 경기장 보정
- `_panel.png` 는 같은 시점의 영상·3D 패널만 잘라 확대한 것, `_page.png` 는 페이지 전체

라벨 읽는 법: 박스 칩 `#트랙ID · 등번호` (번호가 확정된 트랙만 번호 표시), `REF` = 심판(보라색), `GK` = 골키퍼, `BALL` = 공. 3D 트윈의 선수 위 숫자는 트랙 ID.

## 알려진 한계 (화면에서 확인된 것)

1. 질의 모델(4B)이 도구 결과에 없는 등번호를 지어내는 경우가 있다 (d-2). 수치·시점은 도구 결과와 일치했다.
2. 선수가 넘어지는 장면(18.7 s)의 속력 이상값 12.3 m/s.
3. 3D 트윈의 라벨은 트랙 ID 이며 골키퍼 전용 색이 없다.
4. 번호가 확정된 트랙은 51 개 중 14 개 — 와이드 화면에서 등이 보이는 순간이 짧은 선수는 번호가 없다.
