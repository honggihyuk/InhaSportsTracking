# Frontend — Soccer 3D Digital Twin

React 19 + Vite + Three.js 웹 화면입니다.

```bash
npm install
npm run dev      # http://localhost:5173 (백엔드 http://localhost:8000 을 먼저 실행)
```

- 구성 · 화면 기능: [docs/guides/FRONTEND.md](../docs/guides/FRONTEND.md)
