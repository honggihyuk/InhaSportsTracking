# 웹 프론트엔드 가이드

React 19 + Vite + Three.js(React Three Fiber) 기반입니다. 실행 방법은 [설치 · 서버 실행 가이드](./SETUP.md#3-서버-실행).

```bash
cd frontend
npm install
npm run dev       # http://localhost:5173 (백엔드 http://localhost:8000 필요)
npm run build     # dist/ 정적 빌드
npm run lint
```

## 구성

```
frontend/
├── index.html
├── vite.config.js
├── public/                      # 파비콘·아이콘
└── src/
    ├── main.jsx                 # 진입점 (Archivo · Big Shoulders Display · Pretendard 서체를 npm 패키지로 번들)
    ├── App.jsx                  # 화면 구성(히어로 · 스테이지 · 큐) · 영상 ↔ 분석 ↔ 3D 데이터 흐름
    ├── analysis.js              # 보정 기준점, 분석 프레임 → 3D 데이터, 경기장 라인 투영
    ├── index.css                # 디자인 토큰 · 스타일
    └── components/
        ├── api.js               # REST / WebSocket 클라이언트 (API_BASE_URL)
        ├── VideoOverlay.jsx     # 영상 위 탐지 박스 · 보정 라인 · 보정점 canvas
        └── CalibrationPanel.jsx # 수동 보정용 경기장 도면
```

## 화면 구성

[CourtSketch Tracking Viewer](https://courtsketch.com/tracking) 의 구성(히어로 · 스테이지 패널 · 오른쪽 큐)을 축구 분석에 맞게 옮겼습니다.

| 영역 | 내용 |
|---|---|
| 히어로 | 제목 · 분석 모드, 요약 수치(추적 선수 · 공 검출 % · 경기장 보정 % · 이벤트 수), 재생 상태, 영상 업로드 |
| 안내 배너 | 자동 탐지·규칙 기반 추정이라 일부 틀릴 수 있다는 안내 |
| 스테이지 머리 | 가장 최근 이벤트(없으면 영상 이름) · 시각 · 프레임, 이벤트 사이 이동(‹ n / N ›, 큐의 필터 적용) |
| 스테이지 | 경기 영상(탐지 박스 · 보정된 경기장 라인)과 3D 트윈 — 분할 / 영상 / 3D. 영상과 프레임 단위 동기화(`requestVideoFrameCallback`) |
| 출전 선수 띠 | 현재 프레임에 보이는 홈·원정 선수 `#ID` 와 속도(m/s), 공을 가진 선수는 흰 테두리 |
| 재생 컨트롤 · 도구 | 재생/정지, 처음으로, 타임라인 · 화면 구성, 카메라(자유 시점 / 탑다운 / 선수 시점), 탐지 박스 · 경기장 라인 토글, 범례 |
| 오른쪽: 영상 분석 | 모드 선택(고정밀 / 빠른 미리보기), 진행 단계·취소, 자동 보정 · 기준점 직접 지정(보정 중에는 보정 패널로 바뀜) |
| 오른쪽: 큐 | **이벤트** — 패스·턴오버·스프린트 목록, 유형·팀 필터, 누르면 그 장면으로 이동 / **영상** — 라이브러리 · 업로드 |
| 오른쪽: 화면 요소 설명 | 탐지 박스·팀 분류·보정·이벤트 판정 기준 (접이식) |
| 스테이지 아래 | 실시간(경기 시간 · 볼 소유 · 팀 비교 · 볼 속도/위치), 경기 지표(팀 비교 / 선수 표), 경기 질의(VLM) |

## 백엔드 주소 바꾸기

`src/components/api.js` 의 `API_BASE_URL` (기본 `http://localhost:8000`). WebSocket 주소도 여기서 만들어집니다.

## 외부 요청 없음

글꼴은 npm 패키지로 번들되고, 3D 선수 번호 라벨은 canvas 로 그립니다. CDN 이 막힌 환경(교내망·오프라인)에서도 동작합니다.

## 디자인

구성은 CourtSketch 를 따르고, 색은 어둡고 단순하게 맞췄습니다. 표면은 밝기 차이로만 구분하고, 강조색은 재생 · 주요 버튼 · 진행 · 토글 · 상태 배지에만 씁니다. 토큰은 `src/index.css` 의 `:root` 에 있습니다.

| 요소 | 값 |
|---|---|
| 바탕 · 패널 | 녹색 기가 살짝 도는 거의 검정 `#070908` / `#0B0E0C`, 패널 `#0F1311`, 테두리 `#1B211E` · `#29312D` |
| 글자 | `#E6EAE7` / `#98A39D` / `#66716B` |
| 강조색 | 차분한 잔디 그린 `#34C77B` |
| 공 | 노랑 `#F2D64B` (영상의 `BALL` 표시 · 3D 공 · 범례) |
| 팀 기본색 | 홈 `#E5534B` · 원정 `#4A9BF0` (분석 결과가 있으면 유니폼에서 뽑은 색 사용) |
| 제목·큰 수치 | Big Shoulders Display (압축체) |
| 라벨·시간·버튼 | Spline Sans Mono (대문자 고정폭) — 공백은 뺀 범위로 선언해 한글 띄어쓰기가 벌어지지 않게 함 |
| 본문 | Archivo, 한글은 모두 Pretendard 로 대체 |
